# AI Agent Architecture — Diagram

## Controlled agent loop

```mermaid
flowchart TD
    U[User goal] --> I[Input and authorization checks]
    I --> M[Model observes state and messages]
    M --> D{Next action?}
    D -- Ask for missing input --> U
    D -- Final answer --> O[Output validation]
    D -- Tool call --> V[Validate tool, arguments, and permission]
    V -- Rejected --> E[Controlled error or correction]
    V -- Sensitive --> H[Human approval]
    H -- Reject --> E
    H -- Approve --> T[Execute tool]
    V -- Allowed --> T
    T --> R[Tool observation]
    R --> L{Within limits?}
    L -- Yes --> M
    L -- No --> E
    O --> X([END])
    E --> X
```

The model selects only among capabilities exposed to it. Trusted code owns authorization, validation, approval, execution, and termination.

## Information carried through execution

```text
State
├── messages and tool-call pairs
├── task data and current plan
├── tool results
├── step and retry counters
├── approval status
└── errors and trace metadata

Checkpoint + thread ID
└── preserves relevant state across turns or pauses

Long-term store
└── retrieves selected cross-thread information when relevant
```
