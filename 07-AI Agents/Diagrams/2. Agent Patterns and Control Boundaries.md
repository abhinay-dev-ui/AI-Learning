# Agent Patterns and Control Boundaries — Diagram

## Choose the simplest suitable pattern

```mermaid
flowchart TD
    G[Requirement] --> K{Is the sequence known?}
    K -- Yes --> F[Deterministic code, chain, or graph]
    K -- No --> C{Does one agent with tools suffice?}
    C -- Yes --> A[Bounded tool-calling agent]
    C -- No --> S{Do specialists need independent decisions?}
    S -- No --> N[Use functions, tools, or nodes]
    S -- Yes --> MA[Supervisor or handoff multi-agent pattern]
```

## Clinical research boundaries

```mermaid
flowchart LR
    Q[Research request] --> AU[Authenticate and authorize]
    AU --> AG[Bounded research agent]
    AG --> RT[Read-only study tools]
    RT --> EV[Evidence and calculations]
    EV --> EX[Explanation or draft]
    EX --> P{High-impact action?}
    P -- No --> OV[Validate output]
    P -- Yes --> HR[Qualified human review]
    HR --> AC[Authorized action service]
    OV --> Z([Result])
    AC --> Z
```

Authorization and predefined monitoring rules remain deterministic. The agent may retrieve, compare, calculate, classify predefined findings, and explain; humans retain clinical, protocol, and regulatory decisions.
