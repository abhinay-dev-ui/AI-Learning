# Resources

This document contains high-quality references for learning the fundamentals of Large Language Models (LLMs). The resources are categorized to support both conceptual understanding and practical implementation.

---

# Official Documentation

## Hugging Face

- https://huggingface.co/docs
- Comprehensive documentation on Transformers, tokenizers, datasets, and model inference.

---

## Ollama

- https://ollama.com
- Documentation for running and managing open-weight LLMs locally.

---

## OpenAI

- https://platform.openai.com/docs
- API documentation, prompting guides, embeddings, and best practices.

---

## Anthropic

- https://docs.anthropic.com
- Claude API documentation and prompt engineering guides.

---

# Research Papers

## Attention Is All You Need (Transformer)

https://arxiv.org/abs/1706.03762

Introduced the Transformer architecture and Self-Attention mechanism.

---

## BERT

https://arxiv.org/abs/1810.04805

Introduced bidirectional language representation learning.

---

## GPT-3

https://arxiv.org/abs/2005.14165

Demonstrated the power of large-scale autoregressive language models and in-context learning.
