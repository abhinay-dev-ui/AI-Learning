# 3. Training vs Inference

```text
                 Training
                     │
                     ▼
          Large Training Dataset
                     │
                     ▼
             Predict Next Token
                     │
                     ▼
             Compare with Target
                     │
                     ▼
              Adjust Weights
                     │
                     ▼
          Trained Model (.gguf)

────────────────────────────────────────

                Inference

User Prompt
      │
      ▼
Load Trained Model
      │
      ▼
Use Learned Weights
      │
      ▼
Predict Next Token
      │
      ▼
Generate Response
```

### Key Insight

Training learns the weights. Inference only uses them.
