# RAG Resources

## Official Documentation

- [LangChain Documentation](https://python.langchain.com/docs/)
  - RAG pipelines, retrievers, document loaders, vector stores, and retrieval techniques.

- [LlamaIndex Documentation](https://docs.llamaindex.ai/)
  - Data ingestion, indexing, retrieval, and RAG application development.

- [FAISS Documentation](https://faiss.ai/)
  - Similarity search and vector indexing.

- [Chroma Documentation](https://docs.trychroma.com/)
  - Vector database and embedding-based retrieval.

## Research Papers

- **Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks**
  - Original RAG research introducing retrieval-augmented generation.
  - https://arxiv.org/abs/2005.11401

- **REALM: Retrieval-Augmented Language Model Pre-Training**
  - Research on integrating retrieval with language model pre-training.
  - https://arxiv.org/abs/2002.08909

- **Dense Passage Retrieval for Open-Domain Question Answering**
  - Important work on dense vector-based retrieval.
  - https://arxiv.org/abs/2004.04906
