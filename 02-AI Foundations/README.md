# AI Foundations

## Overview

The **AI Foundations** module establishes the conceptual knowledge required before studying Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), AI Agents, and modern GenAI frameworks.

Rather than jumping directly into tools and libraries, this phase focuses on understanding **why modern AI evolved the way it did**. It explains the progression from traditional Artificial Intelligence to Machine Learning, Deep Learning, Artificial Neural Networks, Natural Language Processing, Large Language Models, and Generative AI.

The objective is to build strong mental models that remain valuable regardless of how AI frameworks evolve.

---

# Learning Objectives

After completing this module, you should be able to:

- Explain the evolution of Artificial Intelligence.
- Distinguish between AI, Machine Learning, Deep Learning, and Artificial Neural Networks.
- Understand why Machine Learning replaced many rule-based systems.
- Explain how Deep Learning automatically learns features from data.
- Describe the role of Artificial Neural Networks in modern AI.
- Understand the purpose of Natural Language Processing (NLP).
- Explain what Language Models and Large Language Models are.
- Describe how LLMs generate text using next-token prediction.
- Differentiate between Large Language Models and Generative AI.
- Build a conceptual foundation for studying modern GenAI systems.

# Prerequisites

Before starting this module, you should be comfortable with:

- Basic Python programming

- Object-Oriented Programming (OOP)

- Basic software engineering concepts

No prior knowledge of Artificial Intelligence or Machine Learning is required.

# Why This Module Matters

Modern AI applications—including ChatGPT, Claude, Gemini, Llama, and other Large Language Models—are built on decades of research in Artificial Intelligence, Machine Learning, Deep Learning, and Natural Language Processing.

Understanding these foundational concepts enables you to:

- Learn new AI frameworks more effectively.
- Understand architectural decisions behind AI systems.
- Build production-ready AI applications.
- Make informed engineering decisions instead of relying solely on libraries and APIs.

This module focuses on understanding **why technologies exist**, not just **how to use them**.
