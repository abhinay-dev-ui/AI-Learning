# 1. Artificial Intelligence (AI)

### Definition

The field of building systems capable of performing tasks that normally require human intelligence.

### Primary Goal

Create intelligent systems that can solve complex problems.

### Example / Use Cases

- Self-driving cars
- Virtual assistants
- Fraud detection
- Face recognition

---

# 2. Machine Learning (ML)

### Definition

A subset of AI where systems learn patterns from data instead of relying on manually written rules.

### Primary Goal

Learn from historical data to make predictions or decisions.

### Example / Use Cases

- Spam detection
- Movie recommendations
- Credit scoring
- Demand forecasting

---

# 3. Deep Learning (DL)

### Definition

A subset of Machine Learning that uses multi-layer Artificial Neural Networks to automatically learn features from data.

### Primary Goal

Eliminate manual feature engineering and learn complex patterns automatically.

### Example / Use Cases

- Face recognition
- Speech recognition
- Language translation
- Image classification

---

# 4. Artificial Neural Networks (ANN)

### Definition

A mathematical model consisting of interconnected neurons that learns by adjusting numerical weights during training.

### Primary Goal

Learn complex relationships from data.

### Example / Use Cases

- Image recognition
- Voice assistants
- Large Language Models
- Recommendation systems

---

# 5. Natural Language Processing (NLP)

### Definition

A branch of AI that enables computers to understand, process, and generate human language.

### Primary Goal

Bridge human language and machine understanding.

### Example / Use Cases

- Translation
- Sentiment analysis
- Chatbots
- Grammar correction

---

# 6. Language Models (LM)

### Definition

A model trained to predict the next token by learning statistical patterns in language.

### Primary Goal

Model human language and generate coherent text.

### Example / Use Cases

- Predictive typing
- Smart Compose
- Text generation
- Auto-completion

---

# 7. Large Language Models (LLM)

### Definition

Large-scale Deep Learning models trained on massive datasets using billions of parameters to understand and generate language.

### Primary Goal

General-purpose language understanding and generation.

### Example / Use Cases

- ChatGPT
- Claude
- Gemini
- GitHub Copilot

---

# 8. Generative AI

### Definition

AI systems that generate new content by learning patterns from existing data.

### Primary Goal

Create new text, images, audio, video, and code.

### Example / Use Cases

- ChatGPT
- DALL·E
- Midjourney
- Sora
- Cursor AI

# Why Did AI Evolve?

## Artificial Intelligence

Goal:
Build systems capable of performing tasks that require human intelligence.

Problem:
Writing rules for every possible scenario became impossible.

↓

## Machine Learning

Solution:
Instead of writing rules, let the computer learn patterns from data.

Problem:
Humans still had to manually identify important features in the data.

↓

## Deep Learning

Solution:
Automatically learn features using deep neural networks.

Problem:
A learning mechanism was needed to model highly complex relationships.

↓

## Artificial Neural Networks

Solution:
Use interconnected neurons with learned weights to capture complex patterns.

Problem:
Computers still could not understand human language.

↓

## Natural Language Processing

Solution:
Enable computers to process and analyze human language.

Problem:
Rule-based NLP systems struggled to generalize across languages and tasks.

↓

## Language Models

Solution:
Learn language statistically by predicting the next token.

Problem:
Smaller models had limited knowledge, context, and reasoning ability.

↓

## Large Language Models

Solution:
Scale language models with massive datasets, billions of parameters, and powerful compute.

Problem:
Users wanted AI not only to understand information but also to create new content.

↓

## Generative AI

Solution:
Generate text, images, audio, video, code, and other content from learned patterns.

Result:
Modern AI assistants, copilots, creative tools, and enterprise AI applications.
